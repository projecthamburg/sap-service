# Original brief and current proposal

The original locally supplied October30 design brief was revisited against the working site. Its priority is a credible construction-cleaning business experience: supplied SAP geometry, architectural imagery, English/French, light/dark, phone/tablet/desktop, construction phase terminology, anonymous project/room estimation, real PDF output, plans/photos, careers/availability and a tested embedded calendar. The later owner instructions place both calculator and calendar directly in homepage sections, centralize proposal channels on Project Hamburg, add optional discovery/budget/referral and prepare a future SAP handover.

These paths are implemented. Project and room calculations share one transparent, versioned engine; actual rates remain fictional until Frank's approval. Formal requests and applications use private Canadian storage and a real notification outbox. PDF downloads are actual documents containing their own inputs/calculations and any reviewed plan evidence. Optional plan review goes beyond the original prototype's predefined sample extraction: it calls a real model, records tile/source provenance and leaves uncertainty visible for human decisions.

The original brief explicitly allows paired demonstration imagery for the first prototype when an arbitrary-upload image-editing backend is unavailable. The five current before/after choices are prepared illustrative image pairs. They are not transformations of a visitor's uploaded photo, completed SAP project evidence or guaranteed cleaning outcomes. The interface discloses this, and uploaded photographs remain original. There is no live photo-editing charge hidden in an estimate. A future opt-in uploaded-photo transformation would be a separately tested feature with its own processor consent, fidelity evaluation and cost allowance.

The scheduler is a real booking service. Its guest confirmation bug was found by an actual appointment, corrected only on SAP's route, and retested with five owned identities. Its current guest-email/video-link/cancellation/DST limitations and the handover decisions are documented separately. No unverified hospital contract, endorsement or crew reservation is represented as established merely because the proposal is deployed.
